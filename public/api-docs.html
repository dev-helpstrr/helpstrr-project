Retrieve a paginated list of all customers with filtering and search capabilities.

Parameter Type Required Description

POST /api/v1/customer

Create a new customer account with automatic token generation.

Request Body:

Field Type Required Description
name string Required Customer's full name (max: 255 characters)
email string Required Unique email address
phone string Optional Phone number (must be unique if provided)
password string Required Password (min: 8 characters)
avatar_url string Optional URL to customer's avatar image

{ "name": "John Doe", "email": "john@example.com", "phone": "1234567890", "password": "password123" }

POST /api/v1/customer/bulk-action

Perform bulk operations on multiple customers.

Request Body:

Field Type Required Description
action string Required Action to perform: 'activate', 'deactivate', or 'delete'
customer_ids array|string Required Array of customer IDs or 'all' for all customers

Request Example:

{ "action": "activate", "customer_ids": [1, 2, 3] }

Response (200 OK):

{ "status": "success", "status_code": 200, "status_message": "Bulk activate completed successfully", "data": { "affected_count": 3, "action": "activate" } }

🔒 Authentication

The Customer API uses Laravel Sanctum for authentication. When creating a customer, an API token is automatically generated and returned in the response. This token can be used for authenticated requests.

Using the Token:

Authorization: Bearer {token}

📝 Error Responses

All endpoints return consistent error responses with appropriate HTTP status codes.

Validation Error (422):

{ "message": "The email field is required (and 1 more error)", "errors": { "email": ["The email field is required"], "password": ["The password field is required"] } }

Not Found Error (404):

{ "status": "error", "status_code": 404, "status_message": "Customer not found" }

Server Error (500):

{ "status": "error", "status_code": 500, "status_message": "An error occurred while processing your request" }
